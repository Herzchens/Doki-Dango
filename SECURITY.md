# Security Policy

## Project Status & Supported Versions

Doki-Dango is currently in active pre-production development. There are no supported production releases or stable supported version lines yet.

## Reporting Security Concerns

Do not include vulnerability details, credentials, private keys, service-account data, Firebase installation IDs, FCM registration tokens, personal notification contents, or exploit details in public issues, pull requests, or discussions.

If the repository's Security tab provides a "Report a vulnerability" option, use that GitHub private vulnerability reporting form.

If private vulnerability reporting is not available, do not publish the vulnerability details publicly. Open a public issue containing no sensitive or exploit information and only ask the maintainer to provide a private reporting channel.
