# Security Policy

## Project Status & Supported Versions

Doki-Dango is currently in active pre-production development. There are no production releases or supported stable release lines at this stage.

| Version | Supported |
| :--- | :--- |
| Pre-production / `main` | Best-effort evaluation |

## Reporting Security Concerns

We take the security and privacy of notification data and credentials seriously.

- **Do NOT disclose sensitive information publicly**: Never post credentials, private keys, service account JSON files, FCM tokens / Firebase Instance IDs (FIDs), personal notification contents, or reproducible exploit details in public GitHub issues, pull requests, or discussions.
- **Reporting Mechanism**: If private vulnerability reporting is enabled on GitHub for this repository, please report security issues confidentially using the **"Report a vulnerability"** feature under the repository's **Security** tab.
- **Advisory**: When private vulnerability reporting is not active on this repository, do not submit sensitive security disclosures through public issue trackers. Direct sensitive inquiries confidentially to the repository maintainer through private GitHub channels rather than creating public issue disclosures.
